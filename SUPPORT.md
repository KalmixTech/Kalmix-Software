# Support

## Public GitHub Issues

Use GitHub Issues for reproducible product bugs, compatibility reports, and feature requests. Select the appropriate issue form and include the KALMIX Trace version and Windows version.

Do not post NTRIP usernames or passwords, private caster details, API tokens, customer names, device serial numbers, precise coordinates, or unredacted log files in a public issue.

## Private technical support

For cases that require sensitive logs or account details, contact:

- Email: service@kalmixtech.com
- Support page: https://www.kalmixtech.com/pages/contact

KALMIX typically replies within one to two business days.

## Security issues

Do not open a public issue for a suspected security vulnerability. Follow [SECURITY.md](SECURITY.md).
