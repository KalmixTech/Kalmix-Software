# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to service@kalmixtech.com. Include the affected product and version, a concise description, reproduction steps, and the potential impact.

Do not include NTRIP passwords, API tokens, customer data, precise coordinates, or other secrets unless KALMIX support provides an approved private transfer method.

Please do not open a public GitHub Issue before KALMIX has had an opportunity to review the report.

## Release integrity

Download KALMIX software only from the official `KalmixTech` GitHub organization or from a link on `kalmixtech.com`. Version-specific SHA-256 checksums are published with each release.
